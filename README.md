# comprasCartao
Este projeto em Java simula um cartão de crédito, permitindo registrar compras, controlar o saldo disponível e exibir o histórico de compras. Ele utiliza ArrayList para armazenar as compras, Scanner para entrada de dados e implementa Comparable na classe Compra para possibilitar ordenação por valor. O usuário define o limite do cartão e pode adicionar compras enquanto houver saldo suficiente, sendo informado em caso de saldo insuficiente. Ao final, todas as compras realizadas e o saldo restante são exibidos.Este projeto em Java simula um cartão de crédito, permitindo registrar compras, controlar o saldo disponível e exibir o histórico de compras.
